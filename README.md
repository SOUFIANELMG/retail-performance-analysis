# Retail Performance & Customer Analytics
This project focuses on practical retail analytics.
## Project Overview
This project analyzes retail sales performance, customer behavior, product profitability, and operational performance using Python and Pandas.

The workflow includes:
- Data profiling
- Data cleaning
- Data validation
- Merging multiple datasets
- Revenue and profit calculations
- KPI analysis
- Customer segmentation
- Product and channel analysis
- Operational analysis
- Business insights and recommendations

## Datasets
The project uses three datasets:
- `orders.csv`
- `customers.csv`
- `products.csv`

## Main KPIs
- Realized Revenue: ~63.64M
- Total Profit: ~20.18M
- Average Order Value: ~3596.49
- Profit Margin: ~31.81%
- Delivery Rate: ~60.45%
- Cancel Rate: ~16.83%
- Return Rate: ~8.97%
- Pending Rate: ~13.75%

## Key Findings
- Accessories generated the highest revenue and profit.
- Electronics showed one of the strongest profit margins.
- REGULAR customers generated the highest revenue mainly because of higher order volume.
- The 25-34 age group generated the highest revenue.
- Marrakech generated the highest regional revenue.
- Mobile App was the strongest sales channel in terms of revenue.
- Returned orders had longer shipping times and lower customer ratings.
- Marketplace showed higher average shipping time than the other sales channels.
